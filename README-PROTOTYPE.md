# Secret Santa 2026 — 1차 프로토타입

현재 버전은 UI/동선 테스트용 브라우저 프로토타입입니다.

## 들어간 기능
- 6개 캐릭터 선택
- 캐릭터별 4자리 PIN 최초 등록 / 재로그인
- D-Day 및 선물 상한 설정
- 자기 자신을 제외한 1:1 Secret Santa 추첨
- 일반 사용자는 자신의 상대만 확인
- 홈의 공동 트리 / 진행률 UI
- 숨겨진 관리자 화면: 상단 Secret Santa 로고를 5번 클릭
- 관리자에서 전체 관계 확인 / 재추첨 / 초기화

## 중요
현재 데이터는 `localStorage`에 저장되므로 같은 브라우저 안에서만 공유됩니다. 실제 여섯 명이 각자 휴대폰에서 같은 데이터를 사용하려면 다음 단계에서 Supabase 등 공유 백엔드를 연결해야 합니다.

캐릭터 이미지는 현재 임시 이모지입니다. 원본 6개 PNG를 추가한 뒤 교체할 예정입니다.
